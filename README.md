# ML-Driven-Citizen-Eligibility-Prediction
Machine Learning based system to predict eligibility for Indian government welfare schemes

## Project Description
This project predicts whether a citizen is eligible for Indian government welfare schemes using Machine Learning. 
The model is trained on socio-economic data such as income, family size, employment status, education level, and disability.

## Features Used
- Age
- Gender
- Annual Income
- Family Size
- Education Level
- Employment Status
- Area (Rural/Urban)
- Disability
- Social Category

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit
